# Vocabulario — Gustar y verbos de preferencia

- gustar: to like (literally: to be pleasing)
- encantar: to love (things/activities)
- interesar: to interest
- doler (duele/duelen): to hurt, to ache
- me/te/le/nos/os/les: (to) me/you/him-her-you(formal)/us/you(pl)/them-you(pl)
- a mí / a ti / a él-ella-usted / a nosotros / a vosotros / a ellos-ellas-ustedes: emphasis phrases
- gusta / gustan: like(s) (singular/plural noun)
- duele / duelen: hurts (singular/plural body part)
- mucho / un poco / nada / para nada: a lot / a little / not at all
- el café / el té: coffee / tea
- la música / la película: music / movie
- el concierto / el podcast: concert / podcast
- el tráfico / el ruido: traffic / noise
- la cabeza / la espalda / los ojos / los pies: head / back / eyes / feet
- caminar / leer / estudiar: to walk / to read / to study

---

Pronunciación y uso
- Con «gustar», concuerda el verbo con la cosa: «me gusta el café», «me gustan las películas».
- Usa «a + persona» para claridad: «A Juan le gusta…». Con verbos, usa «gusta + infinitivo»: «Nos gusta leer».
